# 可用级交付方案（M2）

> 起点：`c9c1494`，控制面 + Web 工作台 + 认证计费监控都有了，但**只能命令行启动、只能浏览器访问**。
> 目标：**一个能装到 Mac 上、双击就用、关掉再开还在**的 App，而不是「跑个 go run 打开 localhost」。

---

## 一、怎么算「可用级」

拿四条尺子量，缺一条就是 demo：

| 尺子 | demo 的样子 | 可用级的样子 |
|---|---|---|
| **装** | `go run ./cmd/astra-server` | 双击 `Astra.app` / 拖进 Applications |
| **配** | 自己 `export DEEPSEEK_API_KEY` | 首启向导里粘 key、当场验通 |
| **存** | 数据在 `~/.astra/data`，删了就没了 | 标准路径 + 备份/导出 + 重启不丢 |
| **错** | 终端里一行 panic | App 内错误提示 + 一键导出诊断包 |

再加两条桌面端专属的：**关窗不等于退出**（托盘常驻）、**审批来了要能通知到你**（否则 agent 卡在等人）。

## 二、交付物

1. `Astra.app`（macOS arm64，单文件 bundle，内嵌控制面 + Web）
2. `Astra-<version>.dmg`（拖拽安装 + 首次打开说明）
3. PWA：手机浏览器打开控制面地址可「添加到主屏幕」，窄屏可用
4. `docs/使用说明.md`：从安装到跑通第一个任务

## 三、技术决策

### D1. 桌面壳用 Wails 的 Go runtime，但**不用** `wails build`

`wails build` 要求固定的 `frontend/` 工程结构和 `wails.json`，而我们的前端已经在
`web/` 里由 Vite 构建、并且早被 `internal/api/static.go` 内嵌进二进制了。为了套壳把工程
结构搬一遍，收益为零、风险不小。

所以：**只 import `github.com/wailsapp/wails/v2` 的 runtime，用 `go build` 直接出二进制，
再自己组装 `.app` bundle**（`Contents/MacOS/Astra` + `Info.plist` + `icon.icns`）。

代价：要自己写 Info.plist 和签名脚本。收益：构建链只有 `go build` + `npm run build`，没有第三套工具。

> 已验证：`wails.Run` + `AssetServer.Handler` 反代到本地控制面，WKWebView 里能正常渲染工作台
> （探针读到 `document.title = "Astra · Agent 工作台"`）。SSE 靠 `FlushInterval = -1` 透传。

### D2. 服务与 UI **同进程**

桌面端不 spawn 子进程，直接把 `internal/app` 装起来，监听 `127.0.0.1:0`（内核分配端口），
Wails 窗口通过反代访问。理由：端口冲突不用处理、退出时不会留孤儿进程、日志同一个出口。

### D3. macOS 链接需要显式加 `UniformTypeIdentifiers`

本机只有 Command Line Tools、没有完整 Xcode，Wails 的 darwin 代码引用 `UTType` 会链接失败：

```
Undefined symbols: _OBJC_CLASS_$_UTType
```

构建时必须带 `CGO_LDFLAGS="-framework UniformTypeIdentifiers"`，否则链不过。
这一条写进 Makefile，别再靠人记。

### D4. 构建标签

`go build -tags "desktop,production"`。少了 `desktop` 会在启动时打印
`Wails applications will not build without the correct build tags` 然后退出——不是崩溃，是缺标签。

## 四、模块边界（并行开发不打架）

| 模块 | 目录 | 归属 |
|---|---|---|
| 服务装配 | `internal/app/` | 主干（先落地，其他人依赖它的接口） |
| 桌面壳 | `cmd/astra-desktop/`、`desktop/` | 主干 |
| 首启引导 | `internal/api/setup*.go`、`web/src/pages/Setup.tsx` | 独立 |
| 移动端/PWA | `web/src/styles.css`、`web/public/`、`web/index.html` | 独立 |
| 审批持久化 | `internal/runner/`、`internal/store/` | 独立 |
| 认证加固 | `internal/api/api.go`(SSE)、`internal/auth/`、`internal/llm/pricing.go` | 独立 |

`cmd/astra-server/main.go` 与 `internal/app/` **只由主干改**，其他人需要新配置项时写进提交说明，由主干接。

## 五、`internal/app` 接口（其他模块按这个对齐）

```go
package app

type Config struct {
    Addr     string        // "127.0.0.1:0" 表示内核分配
    DataDir  string
    Provider string        // local / applecontainer / cube
    Agent    string        // shell / dsh / 自定义命令
    AgentEnv map[string]string
    Policy   string
    Cwd      string
    Logger   *log.Logger

    StoreKind   string     // sqlite / postgres / file
    DSN         string
    JWTSecret   []byte
    RequireAuth bool

    LLMGateway   bool
    LLMUpstream  string
    LLMKey       string
    LLMProvider  string
    LLMPublicURL string
    LLMKeyTTL    time.Duration

    Sweep, Idle, MaxAge time.Duration
    Quota               int
}

type Server struct{ /* ... */ }

func New(cfg Config) (*Server, error)     // 装配 + 迁移，不监听
func (s *Server) Start() (addr string, err error) // 监听并后台 serve，返回真实地址
func (s *Server) Err() <-chan error       // serve 期错误
func (s *Server) Meta() map[string]string // provider/agent/policy 展示用
func (s *Server) Shutdown(ctx context.Context) error
func (s *Server) Close() error
```

## 六、验收

- `make test` 全绿（Go + 前端）
- `make app` 产出 `dist/Astra.app`，`open dist/Astra.app` 能起、能登录、能跑一个任务
- `make dmg` 产出可拖拽安装的 dmg
- 关窗后进程仍在托盘、点托盘能唤回；Cmd+Q 才真退出
- 手机浏览器访问同一地址（局域网）可用，能添加到主屏
- 断网/上游 401/沙箱起不来，界面上有明确原因，而不是转圈
